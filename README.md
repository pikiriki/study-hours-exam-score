# study-hours-exam-score
Learning regression with study hours and exam scores.

## Dataset

- Title: Study Hours, Student Scores for Linear Regression
- Publisher: douaa bennoune on Kaggle
- Version: 1
- Source: https://www.kaggle.com/datasets/douaabennoune/study-hours-student-scores-for-linear-regression/versions/1
- File: study_hours_scores_regression.csv
- Listed license: CC0: Public Domain
- License details: https://creativecommons.org/publicdomain/zero/1.0/

### Meaning and origin

The publisher describes 100 randomly generated examples.
Each row pairs simulated study hours with a simulated score.

- Hours: study time in hours; described range 0–10.
- Scores: percentage score; described range 0–100.
- The study-time reporting period is unspecified.
- These are synthetic examples, not verified real-student records.

### Acquisition

Download version 1 from the source page, extract the ZIP,
and place study_hours_scores_regression.csv in the project root.

### Intended use

Practice an ML workflow. Results do not establish real-world
student performance or a causal effect of studying.
